# Sistema de Cadastro de Alunos

Projeto desenvolvido em Java para a disciplina de Linguagem de Programação 1.

## Funcionalidades

- Cadastrar aluno
- Listar alunos
- Buscar aluno por ID
- Atualizar aluno
- Excluir aluno

## Tecnologias

- Java
- IntelliJ IDEA

## Armazenamento

Nesta primeira versão, os alunos são armazenados em memória utilizando ArrayList.
